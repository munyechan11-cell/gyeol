## 1. 결이란 무엇인가요?

**결(Gyeol)**은 식당 사장님이 손님 주문·결제·단골 관리를 한 번에 할 수 있는 무료 프로그램이에요.

### 💡 결로 할 수 있는 일

- 손님이 **QR 코드만 찍으면** 메뉴를 보고 주문해요
- 사장님 **폰으로 새 주문이 왔다고 알림**이 와요
- **영수증이 자동으로 매장 프린터에서 출력**돼요
- 손님이 몇 번 왔는지, 뭘 좋아하는지 **자동으로 기록**돼요
- **단골 손님에게 쿠폰**을 줄 수 있어요
- 매일·매주·매월 **매출을 한눈에** 볼 수 있어요

### 🆓 사용료

- **베타 기간 한정** — 결 사용료 **0원** (무료)
- 인터넷·핸드폰 데이터만 있으면 사용 가능
- 정식 출시 후 사용료는 별도 안내 예정 (베타 매장은 충분한 사전 안내 후 전환)

## 2. 시작하기 — 가입과 매장 설정

### 📱 처음 가입하기 (5분)

#### **단계 1.** 인터넷 주소 열기

핸드폰이나 PC의 인터넷에서 다음 주소를 적어주세요:

```
https://gyeol-app.onrender.com
```

> 💡 한 번 들어가신 후 화면 우측 상단의 **🔖 별표(즐겨찾기)** 또는 핸드폰 **공유 → 홈 화면에 추가** 해두시면 다음부터 빠르게 들어갈 수 있어요.

#### **단계 2.** "사장님으로 시작" 버튼 클릭

화면에 보이는 3개 버튼 중 **사장님** 을 누르세요.

#### **단계 3.** 가입 정보 입력

| 칸 | 입력할 것 |
|---|---|
| **매장 이름** | 예: 결식당, 김밥천국 강남점 |
| **사장님 성함** | 예: 홍길동 |
| **전화번호** | 010-0000-0000 — 로그인 아이디로 씁니다 |
| **비밀번호** | 8자 이상. 문자 인증이 없으니 **잊지 않게 적어 두세요** — 잊으면 관리자(마스터)가 대신 바꿔 줍니다 |

#### **단계 4.** 약관 동의 후 **가입 완료**

---

### 🏪 매장 기본 설정

가입이 끝나면 좌측 메뉴에서 **브랜드 설정** 을 누르세요. 처음 한 번만 설정하면 돼요.

#### 꼭 설정해야 하는 것

1. **매장 이름** — 영수증·QR 인쇄에 사용됨
2. **업종** — 한식·카페·고깃집 등
3. **보상 방식** — 포인트 / 스탬프 / 등급제 중 하나
4. **매장 위치** — "위치 가져오기" 버튼 누르면 자동 입력

#### 나중에 해도 되는 것

- POS 연동 (이지포스·OKPOS 등)
- 알림톡·SMS 연동
- 결제 시스템 연동

> 💡 **순서가 헷갈리시면 먼저 위 4개만 하시면 돼요.**

## 3. 메뉴 등록하기

### 메뉴 추가하는 법

#### **단계 1.** 좌측 메뉴에서 **메뉴 관리** 클릭

#### **단계 2.** 우측 상단 **+ 새 메뉴** 버튼 클릭

#### **단계 3.** 메뉴 정보 입력

| 칸 | 입력 예시 |
|---|---|
| **이름** | 김치찌개 |
| **가격** | 8000 (숫자만) |
| **분류** | 식사류 (예: 식사·찌개·고기·음료·반찬) |
| **설명** | (선택) "매콤하고 진한 국물" |

#### **단계 4.** **저장** 클릭

→ 메뉴 목록에 즉시 추가됩니다.

### 메뉴 품절 표시

매장에서 **김치 떨어졌어요!** 같은 상황엔:
- 메뉴 옆 **토글 스위치** 클릭 → 손님 화면에서 안 보임
- 다시 클릭 → 다시 판매

### 메뉴 수정·삭제

메뉴 우측 **연필** 아이콘 → 수정 또는 **휴지통** 아이콘 → 삭제

## 4. 테이블 배치하기

손님이 어느 자리에 앉을지 정해주는 단계예요.

### 🚀 빠른 방법 — 도면 사진으로 자동 만들기 (AI)

#### **단계 1.** 좌측 메뉴 **테이블 편집** 클릭

#### **단계 2.** **도면 업로드** 버튼

#### **단계 3.** 매장 도면 사진 선택 (또는 손으로 그린 스케치도 OK)

#### **단계 4.** **AI 초안 자동 생성** 클릭

AI가 30초 안에 도면을 분석해서 테이블을 자동으로 배치해줘요.

#### **단계 5.** 결과 확인 → **적용** 클릭

> 💡 AI가 잘못 인식한 자리는 마우스로 끌어서 옮기시면 돼요.

---

### ✋ 수동으로 만드는 법

1. **+ 테이블 추가** 버튼
2. 화면에 새 테이블이 나타남 → 마우스로 끌어서 위치 조정
3. 테이블 클릭 → 우측에서 **인원수·모양(사각/원형)** 변경
4. 끝나면 자동으로 저장됨

### 룸(별실) 설정

- **+ 테이블 추가** → **룸** 선택
- 큰 사각형으로 표시되며 별도로 관리됨

## 5. QR 코드 인쇄 후 테이블에 붙이기

### 인쇄하기

#### **단계 1.** 좌측 메뉴 **QR 인쇄** 클릭

#### **단계 2.** 템플릿 선택

| 종류 | 추천 상황 |
|---|---|
| **디럭스** ⭐ | 처음 사용 — 사용 방법이 자동으로 같이 인쇄됨 |
| **미니멀** | 잉크 절약 |
| **와이드** | 테이블 번호를 크게 보여주고 싶을 때 |

#### **단계 3.** 종이 종류 선택

- **A4 종이** → 잘라서 사용
- **스티커 라벨** → 24칸짜리 라벨지 사용
- **명함 종이** → 10칸짜리

#### **단계 4.** 우측 상단 **인쇄** 버튼

### 테이블에 붙이기

1. 인쇄한 종이를 가위로 자르기
2. 각 테이블 번호 확인
3. 손님이 바로 보이는 위치에 부착 (테이블 모서리, 양념통 옆 등)
4. 투명 시트지나 코팅으로 덮으면 오래 사용 가능

> 💡 **명함 사이즈 종이에 인쇄해서 메뉴판 옆에 끼워두는 방법도 있어요.**

## 6. 영수증 자동 인쇄 프로그램 설치 (선택)

### 🤔 꼭 해야 하나요?

- **POS API가 연동된 매장** → 안 해도 됨 (POS에서 자동 인쇄)
- **POS 없거나 수동 매장** → ⭐ **꼭 설치 권장**

### 설치 방법

#### **단계 1.** 결 웹앱 → **브랜드 설정** → **영수증 자동 인쇄**

#### **단계 2.** **결 인쇄 브릿지 프로그램 다운로드** 클릭

#### **단계 3.** 다운로드된 `결-인쇄-브릿지-Setup-X.X.X.exe` 더블클릭

#### **단계 4.** Windows 보호 경고 발생 시

> ⚠️ "Windows에서 PC를 보호했습니다" 경고는 정상이에요.

→ **추가 정보** → **실행** 클릭

#### **단계 5.** 설치 마법사 진행 (3분)

#### **단계 6.** 설치 완료 후 우측 하단 트레이에 🟢 결 아이콘 생김

### 페어링 (매장 연결)

#### **단계 1.** 결 웹앱 → 브랜드 설정 → 영수증 자동 인쇄

#### **단계 2.** **자동 인쇄 사용** 토글 켜기

#### **단계 3.** **페어링 코드 발급** 클릭 → **6자리 숫자** 표시됨 (예: 483921)

#### **단계 4.** PC 우측 하단 트레이 🟢 결 아이콘 우클릭 → **매장 연결**

#### **단계 5.** 6자리 코드 입력 → **연결**

→ ✅ "결식당 강남점 와 페어링되었어요" 메시지가 나오면 성공!

### 프린터 선택

#### **단계 1.** 같은 창에서 **프린터 선택** 드롭다운

#### **단계 2.** 사용할 영수증 프린터 선택 (EPSON, 빅솔론 등)

#### **단계 3.** 제조사 선택

#### **단계 4.** **테스트 인쇄** 버튼 → 종이가 나오면 끝! 🎉

> 💡 이후 손님이 결제 승인하면 **영수증이 자동으로 출력**됩니다.

## 7. 폰으로 알림 받기 (푸시 알림)

매장 화면을 보지 않고도 **사장님 폰에 알림**이 와요.

### 📱 알림 받는 종류

- 🔔 새 주문 도착
- 💳 손님이 결제 요청
- 🎟 손님이 쿠폰 사용 요청
- 👤 새 직원 가입 요청

### 알림 설정 방법

#### **단계 1.** 결 웹앱 → **브랜드 설정** → **푸시 알림** 섹션

#### **단계 2.** **이 기기로 알림 받기** 버튼 클릭

#### **단계 3.** 브라우저 권한 팝업 → **허용**

→ "이 기기 알림 켜짐 · 총 1대 등록" 메시지가 보이면 성공!

### 여러 기기에서 알림 받기

사장님 폰뿐만 아니라 **태블릿·매장 PC** 어디서든 같은 방법으로 등록.

→ 어떤 기기에서든 결 웹앱 로그인 → 브랜드 설정 → **"이 기기로 알림 받기"**

### 알림 종류별 끄고 켜기

토글 4개로 각각 ON/OFF 가능:
- 새 주문 도착
- 결제 요청
- 쿠폰 사용 요청
- 새 직원 가입 요청

### ⚠️ 주의사항

- **iPhone**: 결 웹앱 열고 → **공유 → 홈 화면에 추가** 한 뒤에만 작동 (iOS 16.4 이상)
- **Android·Windows·Mac**: 그냥 브라우저에서 바로 작동
- **알림 권한 거부했을 때**: 주소창 왼쪽 **🔒 자물쇠 아이콘 → 알림 → 허용** 으로 변경

## 8. 영업 시간 설정하기

영업 시간을 등록하면 **영업 외 시간에 손님 주문이 자동으로 차단**돼요.

### 설정 방법

#### **단계 1.** 결 웹앱 → **브랜드 설정** → **영업 시간** 섹션

#### **단계 2.** 요일별로 영업 시간 입력

예시:
```
월요일 09:00 ~ 22:00
화요일 09:00 ~ 22:00
...
일요일 휴무
```

#### **단계 3.** 휴게 시간 (선택)

점심 후 잠시 닫는 식당이면 **+ 쉬는시간** 클릭 → 시간 입력 (예: 15:00 ~ 17:00)

#### **단계 4.** **24시간 영업** 토글

24시간 운영 매장은 켜기 → 요일별 시간 무시

#### **단계 5.** 특정 날짜 휴무 (명절·임시휴무)

날짜 선택 → **추가** 클릭

#### **단계 6.** **영업 시간 저장** 버튼

### 긴급 임시 마감

갑자기 매장을 닫아야 할 때:

- 매장 상단의 **🟢 영업 중** 칩 클릭 → 🔴 마감으로 즉시 변경
- 사유 입력 (선택): "재료 소진", "사장님 부재" 등
- 다시 클릭하면 영업 재개

→ 손님이 QR 찍어도 **"지금은 주문할 수 없어요"** 안내가 표시됨

## 9. 주문 받기 — 손님이 QR 찍으면

### 흐름 한눈에

```
손님이 QR 찍기
    ↓
손님 회원가입·로그인
    ↓
메뉴 보고 카트 담기
    ↓
주문하기 버튼
    ↓
🔔 사장님 폰에 알림 도착!
    ↓
주문 화면에 새 주문 카드 표시
```

### 사장님이 할 일

#### **단계 1.** 좌측 메뉴 **주문·쿠폰** 클릭

#### **단계 2.** 새 주문 카드 (네이비 강조) 확인

#### **단계 3.** **접수 완료** 버튼 1번 클릭

→ 자동으로 "조리 중" 상태로 변경

#### **단계 4.** 조리 완료 후 **서빙 완료** 버튼 1번 클릭

→ 끝!

> 💡 **사장님이 누르는 버튼은 총 2번이에요.** 다른 POS는 4단계인데, 결은 2단계로 단순화했어요.

### 주문 취소

주문 카드의 **취소** 버튼 클릭 → 확인 → 취소됨

### 영수증 재인쇄

주문 카드의 **재인쇄** 버튼 → 영수증 다시 출력

## 10. 결제 처리하기

### 새 결제 흐름 (2026년 6월 개편)

```
손님이 '결제하기' 누르기
    ↓
💳 사장님 폰에 알림: "결제 요청 — 테이블 N · ₩50,000"
    ↓
사장님: 주문 페이지 → 노란색 "결제 요청" 카드 표시
    ↓
사장님: '결제 승인 + 영수증 출력' 클릭
    ↓
📄 총 영수증 1장 자동 출력 (모든 주문 합산)
    ↓
사장님: 테이블 클릭 → '계산 완료 → 테이블 비우기'
```

### 사장님이 해야 할 일

#### **방법 A: 주문 페이지에서**

1. 좌측 **주문·쿠폰** 클릭
2. 상단 **"💰 결제 요청"** 카드 (노란색)
3. **결제 승인 + 영수증 출력** 클릭

#### **방법 B: 대시보드 테이블 카드에서**

1. **대시보드** → 결제 요청 들어온 테이블 클릭
2. 모달 상단의 **결제 요청** 배너 (노란색)
3. **결제 승인 + 영수증 출력** 클릭
4. 사장님이 결제 받음 (현금·카드 단말기)
5. **계산 완료 → 테이블 비우기** 클릭

### 영수증 출력 우선순위

1순위: POS API 연동 매장 → POS에서 출력
2순위: PC 트레이 앱 (인쇄 브릿지) → 매장 PC 영수증 프린터
3순위: 브라우저 팝업 → 일반 프린터로

### ⚠️ 결제 승인 후 알림

영수증이 안 나오면 사장님에게 **친절한 안내 메시지**가 나와요:
- "프린터 권한이 거부됐어요"
- "프린터 연결이 끊어졌어요"
- "팝업이 차단되어 인쇄할 수 없어요"

## 11. 테이블 관리 — 8단계 흐름

매장의 테이블은 **8가지 상태**로 자동으로 흘러가요.

### 8단계 그림

```
1. ⚪ 비어있음     ← 손님 없음
        ↓
2. 🟣 예약됨       ← 예약 등록하면 자동
        ↓
3. 🟡 세팅완료     ← 사장님이 "준비 완료" 클릭
        ↓
4. 🟢 손님입장     ← 손님이 QR 찍으면 자동
        ↓
5. 🟢 식사중       ← 첫 주문이 들어오면 자동
        ↓
6. 🔵 결제완료     ← 결제 승인하면 자동
        ↓
7. 🟠 정리중       ← "정리 시작" 클릭
        ↓
   다시 비어있음   ← "청소 완료" 클릭
```

### 사장님이 직접 누르는 단계

- **세팅 완료** (③) — 손님 받을 준비
- **정리 시작** (⑦) — 결제 후 정리
- **청소 완료** (→①) — 다음 손님 받을 준비

> 💡 **나머지는 모두 자동으로 흘러갑니다.**

### 테이블 상세 보기

#### **단계 1.** 대시보드에서 테이블 카드 클릭

#### **단계 2.** 모달 창이 열림

#### 표시되는 정보

- 현재 상태 (색깔 + 진행 바)
- **체류 시간** (45분, 1시간 20분 등)
- **인원수**
- **손님 명단**
- **주문 목록** (각 주문의 메뉴·수량·금액·결제상태)
- **합계** + **미결제 합계**

#### 액션 버튼

- 결제 승인
- 계산 완료
- 정리 시작 / 청소 완료
- 중간 영수증 출력
- 퇴장 처리

### 키보드로 모달 닫기

- **ESC 키** → 즉시 닫기

## 12. 예약 받기

### 예약 등록

#### **단계 1.** 좌측 메뉴 **예약** 클릭

#### **단계 2.** 우측 상단 **+ 새 예약** 버튼

#### **단계 3.** 손님 정보 입력

##### 🔍 단골 손님이라면 (이름 검색)

- 이름·전화번호 일부 입력 → 등록된 손님 자동 검색
- 클릭 → 정보 자동 채움

##### 👤 처음 오시는 손님이라면 (게스트로 추가)

- 검색 결과 없으면 **+ 게스트로 추가** 클릭
- 이름·전화번호 한 화면에서 동시 입력
- **게스트 추가** 클릭

#### **단계 4.** 날짜·시간·테이블·인원·메모 입력

#### **단계 5.** **저장**

→ 등록 즉시 해당 테이블이 **보라색 "예약됨"** 으로 표시됨

### 예약 상태 변경

각 예약 카드 하단의 **4가지 상태** 버튼:
- **예약 확정** ✓ (기본)
- **방문 완료** (손님이 와서 식사함)
- **노쇼** (안 옴)
- **취소**

### 예약 취소 / 삭제

- 카드 우측 **휴지통 아이콘** → 삭제
- 또는 상태 → **취소**

→ 해당 테이블이 자동으로 **비어있음**으로 복귀

## 17. 자주 묻는 질문 (FAQ)

### Q1. 인터넷 끊기면 어떻게 되나요?

A. 결은 인터넷이 다시 연결되면 자동으로 동기화돼요.
- 끊긴 동안 손님 QR 주문은 안 됨 (정상)
- 끊긴 동안 사장님이 입력한 데이터는 PC 안에 보관 → 연결되면 자동 전송

### Q2. 영수증 프린터를 안 샀어요. 어떻게 해야 하나요?

A. 두 가지 방법이 있어요.

**방법 A. POS에 표시되는 영수증을 활용**
- POS API 연동 (이지포스 등)
- 또는 POS에 손으로 입력

**방법 B. 일반 A4 프린터로 인쇄**
- 결제 승인 시 브라우저 팝업 → A4 영수증 인쇄

### Q3. 손님이 QR 찍었는데 회원가입을 안 해요.

A. 첫 가입은 1분 정도 걸려요. 손님에게:
- "카카오 또는 구글로 5초 가입 가능해요"
- "이름·전화번호만 입력하시면 단골 적립이 시작됩니다"

### Q4. 다른 매장의 손님도 우리 매장 정보를 볼 수 있나요?

A. 아니에요. 손님은 QR 찍은 매장 정보만 볼 수 있어요. 매장 간 데이터는 완전히 분리되어 있습니다.

### Q5. 결을 안 쓰면 어떻게 되나요?

A. 사장님이 매장을 닫거나 결을 그만 쓰셔도, 손님 데이터는 사장님 동의 후 삭제돼요. 단골 손님 정보는 엑셀로 받아 가실 수 있어요.

### Q6. 다른 매장에서 받은 쿠폰이 우리 매장에서 쓰여요?

A. 아니에요. 쿠폰은 발급한 매장에서만 사용 가능해요.

### Q7. 예약을 받았는데 손님이 안 와요 (노쇼).

A. 예약 카드의 **노쇼** 버튼 클릭 → 자동으로 테이블이 비어있음으로 복귀.
이 손님은 **장기 휴면** 분류로 자동 이동돼요.

### Q8. 인쇄 브릿지 프로그램이 자꾸 꺼져요.

A.
1. 트레이의 결 아이콘 우클릭 → **자동 시작** 체크 확인
2. PC 종료 후 다시 켜기
3. 그래도 안 되면 → 제거 후 재설치

### Q9. 사장님 폰을 새로 바꿨어요. 알림은 어떻게?

A.
1. 옛 폰의 결 웹앱 → 브랜드 설정 → 푸시 알림 → **이 기기에서 알림 끄기**
2. 새 폰에서 결 웹앱 → **이 기기로 알림 받기**

### Q10. 영업 시간 외에 사장님이 직접 주문 입력은 안 되나요?

A. 가능해요. 사장님은 영업 시간 무관하게 주문 페이지에서 수동 입력 가능. 다만 손님 QR 주문만 차단됩니다.

## 18. 문제가 생겼을 때

### ⚡ 즉시 해결할 수 있는 것

#### "화면이 안 떠요" → 새로고침
- PC: `Ctrl + Shift + R`
- 핸드폰: 주소창 옆 **새로고침** 아이콘

#### "주문이 안 보여요" → 알림 권한 확인
1. 브랜드 설정 → 푸시 알림
2. 이 기기 알림이 켜져 있는지 확인
3. 안 켜져 있으면 다시 등록

#### "프린터에서 영수증이 안 나와요"
1. 프린터 전원 확인
2. 종이가 들어가 있는지 확인
3. PC 트레이의 결 아이콘이 🟢 (초록)인지 확인
4. 🟡 노랑이면 인터넷 연결 확인
5. 🔴 빨강이면 우클릭 → 다시 페어링

#### "푸시 알림이 안 와요"
1. 결 웹앱 → 브랜드 설정 → 푸시 알림 → 상태 확인
2. 권한 거부됐다면 → 주소창 왼쪽 🔒 → 알림 → 허용
3. 종류별 토글이 켜져 있는지 확인

#### "결 인쇄 브릿지가 트레이에 안 보여요"
1. 시작 메뉴 → "결 인쇄 브릿지" 검색 → 실행
2. 또는 PC 재시작

### 🆘 그래도 안 될 때

**개발팀 연락처**: (사장님 연락처로 안내)

1. **현재 화면을 사진 또는 캡쳐**
2. **언제 발생했는지** 메모
3. **무슨 작업을 하던 중이었는지** 메모

위 3가지를 보내주시면 빠르게 해결해드려요.
